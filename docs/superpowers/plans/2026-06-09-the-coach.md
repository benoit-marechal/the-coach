# The Coach Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish a static client-side workout runner named The Coach.

**Architecture:** A single static app follows the Parure model: `index.html`, `style.css`, `app.js`, and Node tests. `app.js` exposes pure functions on `window.TheCoach` for testing and keeps DOM rendering separate from state transitions.

**Tech Stack:** HTML, CSS, Vanilla JS, Tailwind CDN, Node built-in test runner, GitHub Pages.
